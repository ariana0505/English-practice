# Lección 8: A, AN, THERE IS y THERE ARE

> Apuntes elaborados a partir del tema del título visible en las capturas. No son una transcripción ni un resumen verificado del contenido del video. Los ejemplos y ejercicios son originales.

## Objetivo

Usar el artículo indefinido y decir que algo existe o está presente en un lugar.

## A y AN: un / una

Se usan con sustantivos **contables en singular**. La elección depende del **sonido inicial de la palabra siguiente**, no simplemente de su primera letra.

| Artículo | Sonido siguiente | Ejemplos |
|---|---|---|
| a | consonántico | a book; a dog; a university |
| an | vocálico | an apple; an egg; an hour |

**University** empieza con un sonido parecido a /y/; la **h** de **hour** no se pronuncia. Si hay un adjetivo, considera su sonido: **an old book**, **a red apple**.

No se dice ❌ *a books* ni ❌ *a water* al hablar de agua en general. Sí: **a book**, **some books**, **some water**, **a glass of water**.

## THERE IS y THERE ARE = hay

| Forma | Singular o no contable | Plural |
|---|---|---|
| Afirmativa | There is a book. | There are two books. |
| Negativa | There isn't a book. | There aren't any books. |
| Pregunta | Is there a book? | Are there any books? |
| Respuesta afirmativa | Yes, there is. | Yes, there are. |
| Respuesta negativa | No, there isn't. | No, there aren't. |

- There is a chair in the room. — Hay una silla en la habitación.
- There is some water. — Hay un poco de agua.
- There are three chairs. — Hay tres sillas.

**Some** suele aparecer en afirmaciones y **any** en preguntas y negaciones de este tipo. No es una regla absoluta para todos los contextos.

## Existencia frente a ubicación

- **There is a book on the table.** — Hay un libro sobre la mesa: introduces su existencia.
- **The book is on the table.** — El libro está sobre la mesa: ubicas un libro ya identificado.

Puedes contraer **there is → there's**. Para estas prácticas, usa **there are** con plural.

## Notas necesarias: A/AN, THE y ausencia de artículo

| Uso | Ejemplo | Idea |
|---|---|---|
| a/an | There is a dog outside. | Introduces un perro sin identificarlo previamente. |
| the | The dog is small. | Hablas de ese perro ya identificado. |
| sin artículo, plural general | Dogs are animals. | Hablas de perros en general. |

Un sustantivo contable singular común normalmente necesita algo delante: **a book**, **the book**, **my book**, **this book**. Evita *There is book*.

### THERE no siempre significa «allí»

En **There is a chair**, la construcción completa significa «hay una silla». Para indicar además «allí»: **There is a chair there** — Hay una silla allí. El primer *there* forma la estructura de existencia; el segundo señala el lugar.

### Negativas equivalentes

- **There isn't any water = There is no water.** — No hay agua.
- **There aren't any chairs = There are no chairs.** — No hay sillas.

No combines ambas negaciones: evita *There aren't no chairs* en el inglés estándar que practicamos aquí.

### SOME y ANY con ejemplos

**There are some apples** — Hay algunas manzanas.  
**Are there any apples?** — ¿Hay manzanas?  
**There aren't any apples** — No hay manzanas.

*Any* no necesita una traducción literal en todos estos ejemplos. En ofrecimientos se puede usar *some*: **Would you like some water?** — ¿Quieres un poco de agua? Esa estructura se estudiará más adelante.

## Práctica

1. ___ apple.
2. ___ university.
3. There ___ two beds.
4. ___ there a bathroom?
5. Niega: There are chairs in the room. (usa *any*)

### Respuestas

1. an. 2. a. 3. are. 4. Is. 5. There aren't any chairs in the room.

## Práctica de aplicación

1. Completa: There ___ some water.
2. Niega con no: There are chairs.
3. Introduce un perro y después descríbelo en otra oración.

### Respuestas explicadas

1. **is. Water es no contable en este uso.**
2. **There are no chairs. El verbo permanece afirmativo.**
3. **Ejemplo: There is a dog. The dog is small. A introduce; the identifica.**

## Resumen

**A/an depende del sonido; there is va con singular o no contable; there are va con plural.**
